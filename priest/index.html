Overview

Two redesigns, one shared goal.

This project explores how Shadow and Discipline Priest could be modernized without losing the ideas that make each spec recognizable. Shadow focuses on controlled pressure conversion. Discipline focuses on capped damage shaping and deliberate recovery.

Shadow

Pressure conversion

Shadow builds pressure through DoTs and Resonance, then converts that setup into priority damage through Voidform windows and payoff abilities.

Discipline

Damage shaping

Discipline no longer directly converts damage into healing. Instead, Atonement delays damage, Contrition stores healing potential, and release spells resolve pressure.

Design Philosophy

The redesigns focus on identity, constraints, and tunability.

Design Focus Shadow Discipline
Fantasy Preservation Shadowform remains the default stance and visual identity. Discipline remains an offensive healer, not a generic reactive healer.
Problem Removed Passive damage duplication and volatile multi-target scaling. Direct damage-to-healing conversion and shield dominance.
New Core System Resonance stores pressure for controlled payoff. Deferred Damage smooths pressure without erasing it.
Player Skill Expression Target choice, Resonance timing, Voidform planning, and payoff execution. Atonement coverage, Contrition buildup, release timing, and mana sustain.
Tuning Constraint Flat damage, caps, target limits, and controlled payoff windows. Deferred Damage cap, Contrition stack limits, and spell-specific mana returns.
Project Scope

What this design resource is meant to show.

Included

  • Problem framing and design goals
  • Core gameplay loop proposals
  • Spell and kit treatment
  • Tradeoffs and failure cases
  • Priority lists and sample timelines
  • Tooltip-style player-facing language

Not included

  • Final numerical tuning
  • Complete talent tree layouts
  • Encounter-by-encounter balance sheets
  • Full simulation or log validation
  • Production UI mockups beyond icon/state examples
Design takeaway: This project is intended to organize modern Priest redesign ideas with clear system reasoning, constraint awareness, and player-facing clarity. It is not a final expansion-ready balance proposal.
